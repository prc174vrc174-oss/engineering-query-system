# 階層標籤篩選

工程紀錄搜尋列的「標籤篩選」位於「重新載入」左側。開啟後逐層選擇標籤，按「套用篩選」生效；選上層包含本層與全部子標籤。搜尋列標籤旁的「×」或篩選視窗的「清除篩選」會立即解除篩選，保留搜尋文字，不必再按套用；取消不改變目前篩選。可同時輸入關鍵字，結果需同時符合關鍵字與標籤。

標籤來自各自 D1 的完整 Markdown，支援 Obsidian 內文標籤及 YAML `tags`（清單或陣列），以 `/` 區分階層。忽略程式碼、註解及網址片段。中文、Emoji 標籤正常保留。階層選單的筆數涵蓋整個 D1，同篇包含多個子標籤時，上層只計一次。

衍生表 `engineering_note_tags` 自動建立與補齊，僅儲存筆記 ID、修改時間及標籤 JSON。同步寫入筆記與標籤在同一個 D1 batch 內完成；讀取標籤時也會補齊既有或更新的筆記，並移除已刪除筆記的標籤。無需改動 Google Drive 原始 Markdown。

空白搜尋即使套用標籤，仍以 SQL 篩選後每次載入 15 筆，按「顯示更多」保留既有勾選狀態。關鍵字搜尋一次回傳全部符合結果，摘要只處理勾選結果；原有必須輸入關鍵字的摘要限制保留。標籤不會加入搜尋反黃或摘要關鍵字。

API：`GET ?action=tags` 回傳 `{tags:[{path,count}]}`；搜尋及分頁加上 `tag=<完整階層路徑>`。不以文字子字串猜測標籤，路徑與子路徑界線精確比對，並使用 D1 綁定參數。
